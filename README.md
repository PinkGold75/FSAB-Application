# Full-Stack-Brown-Application
About:
This project is a prototype which is intended to assist teachers who like to call on students to answer in class. The UI is pretty basic, consisting of an text box which allows the user to input names, a button which adds these names to a list, and a button which allows the user to randomly pick a student from the list.

Installation and start up:
open the terminal and type 'git clone https://github.com/PinkGold75/FSAB-Application.git'
type 'cd FSAB-Application/dirp.io'
type 'npm install' in the terminal
then type 'npm run dev'
open 'http://localhost:5173' in a web browser

Contributions:
I wrote the react code (located in FSAB-Application/dirp.io/app/routes/home.tsx) mostly from scratch and I lightly edited the provided css template (FSAB-Application/dirp.io/app/app.css). Challenges:
The biggest challenge I faced while working on this project was figuring out when anonymous functions (i.e. when the ()=> syntax is used) are needed versus when I can just directly call a normal function. I mostly solved this problem through trial and error, but I also read some resources online to help me better understand when I should use one or the other. Ifound the react.dev docs to be especially helpful.
